## Majestic-2 theme by ThemeWagon team.
---
Thank you for using Majestic-2.

The frontend (Vite + TypeScript) lives in [`frontend/`](frontend/):

```
cd frontend
npm install
npm run dev
```

The backend (Node.js + Express + Prisma) lives in [`backend/`](backend/):

```
cd backend
npm install
npx prisma migrate dev
npm run seed
npm run dev
```

See [`backend/README.md`](backend/README.md) for the API and Railway deploy notes.
